COMO DESPLEGAR ESTE MICROSERVICIO EN RENDER

Este microservicio vive dentro del mismo repositorio que tu app Django,
en la carpeta microservicios/microservicio-insertar-node.

1. Sube TODO el proyecto (la carpeta proyecto-completo entera) a tu
   repositorio de GitHub principal (el mismo de tu app Django).

2. En Render: New + Web Service, conecta ese mismo repositorio.

3. Configuracion:
   Root Directory: microservicios/microservicio-insertar-node
   Runtime: Node
   Build Command: npm install
   Start Command: npm start

4. En Environment Variables, agrega:
   MONGO_URI = tu cadena de conexion completa de MongoDB

5. Deploy. Prueba la ruta raiz (GET /) para confirmar que responde.

RUTAS DISPONIBLES

GET /          -> mensaje de confirmacion
GET /consejos  -> lista todos los consejos (respaldo si falla el microservicio de Python)
POST /insertar -> inserta un consejo nuevo. Cuerpo JSON: { "texto": "nuevo consejo" }
